ADD THESE LINES TO YOUR config.php FILE:

Find this section in your config.php:
```
define('UPLOAD_DIR', __DIR__ . '/uploads/');
define('UPLOAD_URL', 'https://indiawebdesigns.in/app/askus/api/uploads/');
```

Add these lines RIGHT AFTER the UPLOAD_URL line:
```
// Razorpay Configuration
define('RAZORPAY_KEY_ID', 'rzp_test_1DP5mmOlF5G5ag'); // Replace with your actual Razorpay Key ID
define('RAZORPAY_KEY_SECRET', 'your_razorpay_secret_key'); // Replace with your actual Razorpay Secret Key
```
